## ☁️ Integrasi Database Cloud

Portal ini menggunakan arsitektur cloud terdistribusi:
- Data disimpan di peramban dan dapat disinkronkan secara real-time ke **Firebase Realtime Database (100% Gratis)**.
- Setiap pengelola mengunggah warta, membuat kolase, atau menambah jadwal/renungan, jemaat yang membuka tautan di atas akan melihat perubahannya secara otomatis.

## 🌟 Fitur Unggulan

1. **Lembar Warta Jemaat HD & Penampil Statis**:
   - Indikator sentuh perbesar tidak bergeser saat warta di-scroll.
   - Penampil layar penuh (*lightbox*) dengan kontrol zoom dan tombol unduh.
2. **Pembersihan Otomatis Warta Kedaluwarsa (> 30 Hari)**:
   - Warta yang usianya melebihi 30 hari otomatis dibersihkan dan diganti notifikasi ramah bagi pengelola.
3. **Kolase 2 Kolom Otomatis (Zero-Crop HD)**:
   - Mengurutkan foto secara alami berdasarkan nama file (A-Z / 1-9).
   - Foto mentah otomatis dibersihkan setelah kolase berhasil diterapkan.
4. **Tabel Jadwal Ibadah Rapi**:
   - Diurutkan dari hari Minggu, lalu jam ibadah.
5. **Dokumentasi Kegiatan & Renungan Harian**:
   - Galeri foto per album/folder.
   - Arsip renungan dengan struktur folder berjenjang (*folder dalam folder*).
